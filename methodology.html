현재 공개 범위: 설계 설명과 수동 확인 안내입니다. 소유 앱의 공개 진입 경로는 아직 확인하지 못했습니다. 자동 탐지의 정확도·실제 방문 검증·고객 사용을 확인한 보고서가 아닙니다.

1. 운영 서약 (NoSponsorPledge)

대가성 노출을 일반 추천과 섞지 않으려는 설계 원칙입니다. 원칙의 선언과 실제 계약·결제·랭킹 경로의 운영 검증은 다릅니다. 지금 이 페이지는 후자를 인증하지 않습니다.

2. 측면별 별점 (AspectRating)

맛·가격·서비스·분위기를 나눠 기록하려는 설계입니다. 어떤 메뉴와 시간대·동행 조건에서 관측했는지 같이 남겨야 취향과 경험을 구분할 수 있습니다. 축별 평가도 객관적 진실은 아닙니다.

3. 상황 적합도 (OccasionFit)

데이트·기념일·조용한 대화·뷰·모임 같은 목적에 맞춰 조건을 구분하려는 설계입니다. 예를 들어 대화가 중요하면 좌석·소음 관련 경험을 찾아보고, 최신 영업·예약 조건은 따로 확인합니다. 목적별 가중치의 효과나 실패 없는 선택은 검증하지 않았습니다.

4. 방문 증명 (VisitProof)

사진·서명·시각·위치 신호를 연결하고 재사용 위험을 줄이려는 설계입니다. 서명은 사진 속 행위·촬영자의 식사·평가의 진실성까지 증명하지 않습니다. 공개 재현 사례·공격 시험·기관 보안 검토를 완료했다고 말하지 않으며, 이 웹페이지는 위치나 사진을 받지 않습니다.

5. 큐레이터의 안목 (CuratorNote)

선택 이유와 제외한 이유를 함께 설명하려는 설계입니다. 직접 관측, 다른 사람의 정보, 개인 취향을 섞지 않고 구분합니다. 큐레이터의 말만으로 실제 방문이나 무대가 관계를 검증한 것으로 취급하지 않습니다.

6. 반증조건 (정직 고지)

대가성 노출을 일반 추천으로 숨기거나 허구 후기를 실제 방문으로 표시한다면 이 설계의 신뢰 원칙에 어긋납니다. 공개 사례가 생기면 관측 시점·범위·오탐과 누락을 같이 평가합니다. 원칙이 있다는 것과 이미 지켰다는 증거는 구분합니다.

7. 무엇을 하지 않는가

이 안내는 외부 리뷰 수집·재게시·협찬 여부 판정을 실행하지 않습니다. 자동 API 이용과 원문 수집의 약관·권한·법률 검토가 완료됐다는 뜻도 아닙니다. 검증되지 않은 법률·판례 적용이나 다른 서비스의 실패 원인 단정은 이전 글의 결론으로 유지하지 않습니다.
